# Quiz Application

Приложение для создания и прохождения интерактивных квизов с поддержкой различных типов вопросов.

## Описание

Quiz Application — это десктопное приложение на Python с графическим интерфейсом (PyQt6), которое позволяет создавать и проходить квизы с различными типами вопросов. Приложение поддерживает работу как с отдельными JSON-файлами квизов, так и с встроенными квизами в исполняемом файле.

## Возможности

- **5 типов вопросов:**
  - Одиночный выбор (single_choice)
  - Множественный выбор (multiple_choice)
  - Текстовый ввод (text_input)
  - Сопоставление (matching)
  - Упорядочивание (ordering)

- **Поддержка изображений** в вопросах (локальные файлы и URL)
- **Валидация** квизов по JSON Schema
- **Сборка в исполняемый файл** с помощью Nuitka
- **Встраивание квизов** в исполняемый файл
- **Кросс-платформенная сборка** (Linux, Windows, macOS)

## Требования

- Python 3.10 или выше
- [uv](https://github.com/astral-sh/uv) — менеджер пакетов Python
- Для сборки: Nuitka 2.8.9 или выше
- Для Linux: patchelf (для standalone режима)

## Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd Quizz
```

2. Установите зависимости с помощью uv:
```bash
uv sync
```

Если у вас не установлен `uv`, установите его:
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

## Использование

### Запуск приложения

1. **С квизом из папки `quiz/`:**
   - Поместите JSON-файл(ы) квиза в папку `quiz/`
   - Запустите приложение:
   ```bash
   uv run python main.py
   ```

2. **С указанием пути к квизу:**
   ```bash
   uv run python main.py /path/to/quiz.json
   # или
   uv run python main.py /path/to/quiz/folder
   ```

3. **С примером квиза:**
   - Если папка `quiz/` пуста или не существует, приложение загрузит пример квиза

### Создание квиза

Создайте JSON-файл согласно схеме (см. [Инструкцию по созданию JSON-схемы](QUIZ_JSON_INSTRUCTION.md)).

Пример структуры:
```json
{
  "title": "Название квиза",
  "description": "Описание квиза",
  "author": "Автор",
  "version": "1.0.0",
  "questions": [
    {
      "id": "q1",
      "type": "single_choice",
      "question": "Текст вопроса",
      "options": ["Вариант 1", "Вариант 2", "Вариант 3"],
      "correct_answer": 0,
      "points": 1
    }
  ]
}
```

## Сборка исполняемого файла

### Обычная сборка (без встроенного квиза)

```bash
./build.sh
```

Исполняемый файл будет создан в папке `build/`. Для использования:
1. Поместите исполняемый файл в любую папку
2. Создайте папку `quiz` рядом с исполняемым файлом
3. Поместите JSON-файлы квизов в папку `quiz`
4. Запустите исполняемый файл

### Сборка с встроенным квизом

```bash
# С квизом из JSON-файла
./build.sh /path/to/quiz.json

# С квизом из папки
./build.sh /path/to/quiz/folder

# Для конкретной платформы
./build.sh /path/to/quiz.json --platform windows
./build.sh /path/to/quiz.json --platform macos
./build.sh /path/to/quiz.json --platform linux
```

Исполняемый файл будет содержать встроенный квиз и изображения, что позволяет распространять его как единый файл.

### Альтернативный способ сборки

```bash
uv run python main.py --build /path/to/quiz.json
uv run python main.py --build /path/to/quiz.json --platform windows
```

## Поддерживаемые форматы JSON

Приложение поддерживает два формата JSON-схемы:

1. **Стандартный формат** (рекомендуется) — соответствует JSON Schema в `schema/quiz_schema.json`
2. **Упрощенный формат** — автоматически конвертируется в стандартный формат

Подробнее см. [Инструкцию по созданию JSON-схемы](QUIZ_JSON_INSTRUCTION.md).

## Зависимости

- **PyQt6** >= 6.6.0 — графический интерфейс
- **jsonschema** >= 4.20.0 — валидация JSON
- **requests** >= 2.31.0 — загрузка изображений по URL
- **nuitka** >= 2.8.9 — компиляция в исполняемый файл (для сборки)
