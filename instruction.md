# Как работает Квиз (main.py)

Этот файл объясняет, как устроена программа квиза. Она написана на Python и использует только стандартные библиотеки, встроенные в язык по умолчанию.

## 1. Библиотеки (Импорты)
Мы используем следующие стандартные модули:
- `json`: для чтения файла с вопросами (`questions-auto.json`).
- `time`: для создания задержки в 3 секунды.
- `subprocess`: для запуска сторонней программы (Paint) из кода.
- `os`: для работы с путями к файлам.

## 2. Загрузка данных
Программа открывает файл `questions-auto.json` и превращает его в словарь Python с помощью `json.load()`. Если файл не найден, программа выводит ошибку и завершается.

## 3. Игровой цикл
Программа проходит по каждому вопросу в цикле `for`:
1. Выводит текст вопроса и варианты ответов.
2. Ждет ввода пользователя через `input()`.
3. Сравнивает ответ с правильным (`correct_answer`).
4. Если ответ верный — прибавляет 1 к счету и выбирает "хорошую" картинку.
5. Если неверный — показывает правильный ответ и выбирает "плохую" картинку.

## 4. Показ картинок (Библиотека lib)
Теперь программа не зависит от установленных в системе программ (как Paint) или библиотек.
1. Все нужные файлы лежат в папке `lib/`.
2. Программа сама добавляет этот путь в настройки Python при запуске.
3. Окно с картинкой создается через `tkinter` (стандартное средство Python), а для чтения разных форматов (JPG, PNG) используется встроенная библиотека `Pillow`.
4. Окно открывается в центре экрана и автоматически закрывается через 3 секунды.

## 5. Итоги
В конце программа выводит итоговый счет игрока и небольшое поздравление или напутствие.
