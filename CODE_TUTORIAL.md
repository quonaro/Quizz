## 📖 Введение

Это приложение-викторина на Python с графическими элементами. Программа:
- Задает вопросы в консоли
- Показывает картинки при правильных/неправильных ответах
- Повторяет вопрос до получения правильного ответа
- Может быть скомпилирована в EXE-файл

### Используемые технологии:
- **Python 3.x** - язык программирования
- **Tkinter** - встроенная библиотека для создания окон
- **Pillow (PIL)** - библиотека для работы с изображениями
- **PyInstaller** - инструмент для сборки в EXE

### 2. Функция `get_resource_path()`

```python
def get_resource_path(relative_path):
    if hasattr(sys, '_MEIPASS'):
        return os.path.join(sys._MEIPASS, relative_path)
    return os.path.abspath(relative_path)
```

**Что делает:**
Эта функция решает важную проблему: когда программа скомпилирована в EXE, файлы находятся не там, где обычно.

**Как работает:**
1. PyInstaller при создании EXE распаковывает все файлы во временную папку
2. Путь к этой папке хранится в `sys._MEIPASS`
3. Функция проверяет: если `_MEIPASS` существует - используем его
4. Если нет - используем обычный путь (для запуска как скрипт)

**Пример:**
```python
# При запуске как скрипт:
get_resource_path("images/image1.png")  
# Вернет: "C:/Users/dd/Documents/git/Quizz/images/image1.png"

# При запуске как EXE:
get_resource_path("images/image1.png")
# Вернет: "C:/Users/dd/AppData/Local/Temp/_MEI123456/images/image1.png"
```


**Параметры:**

- `duration` - время показа в секундах (по умолчанию 3)

**Пошаговый разбор:**

#### Шаг 1: Получение пути и проверка файла
```python
full_path = get_resource_path(image_path)

    print(f"Ошибка: Файл не найден по пути: {full_path}")
```

#### Шаг 2: Создание окна
```python
root = tk.Tk()
root.title("Quiz Image")
root.attributes("-topmost", True)  # Окно поверх всех
root.overrideredirect(True)        # Убираем рамки
```
- Создаем главное окно Tkinter
- Делаем его поверх всех окон
- Убираем заголовок и кнопки (чистое окно с картинкой)

#### Шаг 3: Загрузка изображения
```python
img = Image.open(full_path)
img.thumbnail((600, 600))  # Масштабируем
photo = ImageTk.PhotoImage(img)
label = tk.Label(root, image=photo, bg="black")
label.pack()
```
- Открываем изображение через PIL
- Уменьшаем до максимум 600x600 (сохраняя пропорции)
- Конвертируем в формат Tkinter
- Создаем метку с изображением на черном фоне

#### Шаг 4: Центрирование окна
```python
root.update_idletasks()
width = root.winfo_width()
height = root.winfo_height()
x = (root.winfo_screenwidth() // 2) - (width // 2)
y = (root.winfo_screenheight() // 2) - (height // 2)
root.geometry(f'{width}x{height}+{x}+{y}')
```
- Обновляем окно, чтобы получить его размеры
- Вычисляем координаты центра экрана
- Размещаем окно по центру

#### Шаг 5: Автоматическое закрытие
```python
root.after(int(duration * 1000), root.destroy)
root.mainloop()
```
- Планируем закрытие окна через `duration` секунд
- Запускаем главный цикл окна (окно отображается)

### 4. Функция `ask_question()`

```python
def ask_question(lines, correct_answer, success_img):
    # Задает вопрос и проверяет ответ
```

**Параметры:**
- `lines` - список строк с вопросом и вариантами ответов
- `correct_answer` - правильный ответ (строка или список строк)
- `success_img` - путь к картинке для правильного ответа

**Пошаговый разбор:**

#### Шаг 1: Вывод вопроса
```python
while True:
    for line in lines:
        print(line)
    otvet = input("Enter answer: ")
```
- Бесконечный цикл (выходим только при правильном ответе)
- Выводим все строки вопроса
- Получаем ответ от пользователя

#### Шаг 2: Проверка ответа
```python
is_correct = False

if isinstance(correct_answer, list):
    if otvet in correct_answer:
        is_correct = True
elif otvet == correct_answer:
    is_correct = True
```
- Проверяем тип правильного ответа
- Если это список - проверяем, есть ли ответ в списке
- Если это строка - сравниваем напрямую

#### Шаг 3: Обработка результата
```python
if is_correct:
    print("Correct!")
    kartinka(success_img)
    break
else:
    print("Wrong! Try again.")
    kartinka(r"images\image2.png")
```
- При правильном ответе - показываем картинку успеха и выходим
- При неправильном - показываем картинку ошибки и повторяем вопрос

## ➕ Как добавить свои вопросы

### Простой вопрос с одним правильным ответом:

```python
ask_question([
    "Какая столица России?",
    "1: Москва",
    "2: Санкт-Петербург",
    "3: Казань",
    "4: Новосибирск"
], "1", r"images\my_success_image.png")
```

### Вопрос с несколькими правильными ответами:

```python
ask_question([
    "Какие из этих городов находятся в России?",
    "1: Москва",
    "2: Париж",
    "3: Санкт-Петербург",
    "4: Лондон"
], ["1", "3"], r"images\my_success_image.png")
```

**Важно:**
- Правильный ответ - это **строка** (в кавычках): `"1"`, а не число `1`
- Для нескольких ответов используйте **список**: `["1", "3"]`
- Путь к изображению пишите с префиксом `r` и обратными слешами: `r"images\file.png"`

## 🖼️ Как изменить изображения

### Добавление нового изображения:

1. Поместите изображение в папку `images/`
2. Используйте его в вопросе:
```python
ask_question([
    "Ваш вопрос?",
    "1: Вариант 1",
    "2: Вариант 2"
], "1", r"images\your_new_image.png")
```

### Изменение картинки ошибки:

По умолчанию при неправильном ответе показывается `images\image2.png`.
Чтобы изменить это для конкретного вопроса, нужно модифицировать функцию `ask_question`.

**Вариант 1:** Добавить параметр для картинки ошибки:
```python
def ask_question(lines, correct_answer, success_img, error_img=r"images\image2.png"):
    # ... код ...
    else:
        print("Wrong! Try again.")
        kartinka(error_img)  # Используем переданную картинку
```

Теперь можно вызывать:
```python
ask_question([...], "1", r"images\success.png", r"images\my_error.png")
```

## 🔨 Сборка в EXE

### Использование build_exe.py:

```bash
python build_exe.py
```

Этот скрипт:
1. Собирает все файлы (код, изображения, библиотеки)
2. Создает один EXE-файл
3. Сохраняет его в папку `dist/`

### Что включается в EXE:
- Весь код из `main.py`
- Все изображения из папки `images/`
- Библиотека PIL из папки `lib/`
- Файл `questions-auto.json`

### Результат:
- Файл: `dist/Quiz.exe`
- Размер: ~15-20 МБ
- Не требует установки Python на компьютере пользователя

## 🐛 Решение проблем

### Проблема: "Картинка не открылась"

**Причина:** Файл изображения не найден

**Решение:**
1. Проверьте, что файл существует в папке `images/`
2. Проверьте правильность имени файла (регистр важен!)
3. Убедитесь, что используете правильный формат пути: `r"images\file.png"`

### Проблема: Окно с картинкой не появляется

**Причина:** Окно может быть скрыто за другими окнами

**Решение:**
- Программа уже использует `root.attributes("-topmost", True)`
- Проверьте, не блокирует ли антивирус создание окон

### Проблема: EXE не запускается

**Причина:** Отсутствуют необходимые файлы

**Решение:**
1. Убедитесь, что все файлы из папки `dist/` скопированы
2. Проверьте, что антивирус не блокирует EXE
3. Запустите через командную строку, чтобы увидеть ошибки:
```bash
cd dist
Quiz.exe
```

### Проблема: Вопросы на русском отображаются неправильно

**Причина:** Проблемы с кодировкой

**Решение:**
1. Сохраните `main.py` в кодировке UTF-8
2. Добавьте в начало файла:
```python
# -*- coding: utf-8 -*-
```
