## [ЧТО ТАКОЕ PYTHON И КАК ОН РАБОТАЕТ]

### Что такое Python?

Python - это язык программирования. Представь, что это как иностранный язык, только на нём ты разговариваешь не с людьми, а с компьютером.

**Почему Python?**
- Простой и понятный синтаксис (легко читать и писать)
- Много готовых библиотек (как конструктор Lego - берёшь готовые детали)
- Популярный (много уроков и помощи в интернете)

### Как работает программа?

```
1. Ты пишешь код в файле main.py
2. Python читает твой код строка за строкой (сверху вниз)
3. Python выполняет команды, которые ты написал
4. Программа делает то, что ты ей сказал
```

**Пример:**
```python
print("Привет!")  # Компьютер выведет: Привет!
```

## [ОСНОВЫ PYTHON КОТОРЫЕ НУЖНО ЗНАТЬ]

Перед тем как разбирать нашу программу, давай изучим основы Python.

### 1. Переменные - это коробочки для хранения данных

**Что такое переменная?**
Переменная - это как коробка с названием, в которую ты можешь положить что-то.

```python
# Создаём переменную с именем "имя" и кладём туда текст "Вася"
имя = "Вася"

# Создаём переменную "возраст" и кладём туда число 15
возраст = 15

# Теперь можем использовать эти переменные
print(имя)      # Выведет: Вася
print(возраст)  # Выведет: 15
```

**Типы данных:**
```python
# Строка (текст) - пишется в кавычках
название = "Quiz"

# Число целое
количество = 10

# Число с точкой
температура = 36.6

# Список - несколько значений в одной переменной
цвета = ["красный", "синий", "зелёный"]

# True/False (правда/ложь)
правильный_ответ = True
```

### 2. Функции - это мини-программы внутри программы

**Что такое функция?**
Функция - это блок кода, который делает одну конкретную задачу. Ты можешь вызывать её много раз.

```python
# Создаём функцию
def поздороваться():
    print("Привет!")
    print("Как дела?")

# Вызываем функцию
поздороваться()  # Выведет: Привет! Как дела?
поздороваться()  # Выведет: Привет! Как дела?
```

**Функция с параметрами:**
```python
# Функция, которая принимает имя
def поздороваться_с_именем(имя):
    print("Привет, " + имя + "!")

# Вызываем с разными именами
поздороваться_с_именем("Вася")   # Привет, Вася!
поздороваться_с_именем("Маша")   # Привет, Маша!
```

**Функция, которая возвращает результат:**
```python
def сложить(a, b):
    результат = a + b
    return результат

# Используем функцию
сумма = сложить(5, 3)
print(сумма)  # Выведет: 8
```

### Часть 2: Функция get_resource_path - находим файлы

```python
def get_resource_path(relative_path):
    """
    Эта функция помогает найти файлы.
    Работает и когда программа - это скрипт (.py),
    и когда программа - это готовый .exe файл
    """
    # Проверяем: программа запущена как EXE?
    if hasattr(sys, '_MEIPASS'):
        # Да! Значит файлы в специальной временной папке
        return os.path.join(sys._MEIPASS, relative_path)
    # Нет! Значит файлы рядом с main.py
    return os.path.abspath(relative_path)
```

**Разбираем по шагам:**

1. **`def get_resource_path(relative_path):`**
   - `def` - создаём функцию
   - `get_resource_path` - имя функции
   - `(relative_path)` - функция принимает один параметр (путь к файлу)

2. **`if hasattr(sys, '_MEIPASS'):`**
   - `hasattr` - "проверь, есть ли у sys свойство _MEIPASS"
   - `_MEIPASS` - специальная папка, которую создаёт PyInstaller при сборке EXE

3. **`return os.path.join(sys._MEIPASS, relative_path)`**
   - `os.path.join` - "склей два пути в один"
   - `return` - "верни результат"

**Пример работы:**
```python
# Когда программа - это main.py:
путь = get_resource_path("images/cat.png")
# Вернёт: "C:/Users/Вася/Quiz/images/cat.png"

# Когда программа - это Quiz.exe:
путь = get_resource_path("images/cat.png")
# Вернёт: "C:/Users/Вася/AppData/Local/Temp/_MEI12345/images/cat.png"
```

### Часть 3: Функция kartinka - показываем картинку

Эта функция создаёт окно и показывает в нём картинку на несколько секунд.

```python
def kartinka(image_path, duration=3):
    """
    Показывает картинку в окне
    image_path - путь к картинке
    duration - сколько секунд показывать (по умолчанию 3)
    """
```

**Шаг 1: Проверяем, что файл существует**
```python
    try:
        # Получаем полный путь к картинке
        full_path = get_resource_path(image_path)
        
        # Проверяем: файл существует?
        if not os.path.exists(full_path):
            print(f"Ошибка: Файл не найден по пути: {full_path}")
            return  # Выходим из функции
```

**Что тут происходит:**
- `try:` - "попробуй выполнить код, если будет ошибка - не ломайся"
- `os.path.exists(full_path)` - "проверь, существует ли файл"
- `if not` - "если НЕ существует"
- `return` - "выйди из функции (дальше не выполняй)"

**Шаг 2: Создаём окно**
```python
        # Создаём главное окно
        root = tk.Tk()
        root.title("Quiz Image")  # Название окна
        
        # Окно всегда поверх других окон
        root.attributes("-topmost", True)
        
        # Убираем рамку окна (кнопки закрыть, свернуть и т.д.)
        root.overrideredirect(True)
```

**Что тут происходит:**
- `tk.Tk()` - "создай новое окно"
- `root.title("Quiz Image")` - "установи название окна"
- `root.attributes("-topmost", True)` - "окно всегда сверху"
- `root.overrideredirect(True)` - "убери рамку окна"

**Шаг 3: Загружаем и показываем картинку**
```python
        # Открываем картинку
        img = Image.open(full_path)
        
        # Уменьшаем до 600x600 (если больше)
        img.thumbnail((600, 600))
        
        # Конвертируем в формат для Tkinter
        photo = ImageTk.PhotoImage(img)
        
        # Создаём метку с картинкой
        label = tk.Label(root, image=photo, bg="black")
        label.pack()  # Размещаем метку в окне
```

**Что тут происходит:**
- `Image.open(full_path)` - "открой картинку"
- `img.thumbnail((600, 600))` - "если картинка больше 600x600, уменьши её"
- `ImageTk.PhotoImage(img)` - "преобразуй картинку в формат Tkinter"
- `tk.Label(root, image=photo, bg="black")` - "создай метку с картинкой на чёрном фоне"
- `label.pack()` - "размести метку в окне"

**Шаг 4: Центрируем окно на экране**
```python
        # Обновляем окно, чтобы узнать его размер
        root.update_idletasks()
        
        # Получаем ширину и высоту окна
        width = root.winfo_width()
        height = root.winfo_height()
        
        # Вычисляем координаты центра экрана
        x = (root.winfo_screenwidth() // 2) - (width // 2)
        y = (root.winfo_screenheight() // 2) - (height // 2)
        
        # Размещаем окно по центру
        root.geometry(f'{width}x{height}+{x}+{y}')
```

**Математика центрирования:**
```
Экран: 1920 пикселей в ширину
Окно: 400 пикселей в ширину

Центр экрана: 1920 / 2 = 960
Начало окна: 960 - (400 / 2) = 960 - 200 = 760

Окно будет от 760 до 1160 пикселя - ровно по центру!
```

**Шаг 5: Автоматически закрываем окно**
```python
        # Закрой окно через duration секунд
        root.after(int(duration * 1000), root.destroy)
        
        # Запусти главный цикл окна (показывай окно)
        root.mainloop()
        
    except Exception as e:
        # Если произошла ошибка - выведи сообщение
        print(f"Картинка не открылась: {e}")
```

**Что тут происходит:**
- `root.after(3000, root.destroy)` - "через 3000 миллисекунд (3 секунды) вызови функцию root.destroy"
- `root.destroy` - "закрой окно"
- `root.mainloop()` - "запусти главный цикл (показывай окно пока не закроют)"
- `except Exception as e:` - "если произошла любая ошибка, выполни этот код"

### Часть 4: Функция ask_question - задаём вопрос

Это главная функция нашей викторины!

```python
def ask_question(lines, correct_answer, success_img):
    """
    Задаёт вопрос и проверяет ответ
    lines - список строк с вопросом
    correct_answer - правильный ответ
    success_img - картинка при правильном ответе
    """
```

**Шаг 1: Бесконечный цикл вопроса**
```python
    # Цикл будет повторяться, пока не дадут правильный ответ
    while True:
        # Выводим все строки вопроса
        for line in lines:
            print(line)
        
        # Получаем ответ от пользователя
        otvet = input("Enter answer: ")
```

**Что тут происходит:**
- `while True:` - "повторяй бесконечно (пока не скажу остановиться)"
- `for line in lines:` - "для каждой строки в списке lines"
- `print(line)` - "выведи строку"
- `input("Enter answer: ")` - "покажи текст и жди, пока пользователь введёт ответ"

**Пример:**
```python
lines = [
    "Сколько будет 2+2?",
    "1: Три",
    "2: Четыре",
    "3: Пять"
]

# Программа выведет:
# Сколько будет 2+2?
# 1: Три
# 2: Четыре
# 3: Пять
# Enter answer: _  (курсор мигает, ждёт ввода)
```

**Шаг 2: Проверяем ответ**
```python
        # Создаём переменную для проверки
        is_correct = False
        
        # Если правильных ответов несколько (список)
        if isinstance(correct_answer, list):
            if otvet in correct_answer:
                is_correct = True
        # Если правильный ответ один (строка)
        elif otvet == correct_answer:
            is_correct = True
```

**Что тут происходит:**
- `is_correct = False` - "создай переменную, изначально ответ неправильный"
- `isinstance(correct_answer, list)` - "проверь, является ли correct_answer списком"
- `if otvet in correct_answer:` - "если ответ есть в списке правильных ответов"
- `elif otvet == correct_answer:` - "иначе если ответ равен правильному ответу"

**Примеры:**
```python
# Случай 1: Один правильный ответ
correct_answer = "2"
otvet = "2"
# otvet == correct_answer → True

# Случай 2: Несколько правильных ответов
correct_answer = ["1", "2", "3"]
otvet = "2"
# otvet in correct_answer → True (2 есть в списке)
```

**Шаг 3: Реагируем на ответ**
```python
        # Если ответ правильный
        if is_correct:
            print("Correct!")  # Выводим "Правильно!"
            kartinka(success_img)  # Показываем картинку успеха
            break  # ВЫХОДИМ из цикла while
        # Если ответ неправильный
        else:
            print("Wrong! Try again.")  # Выводим "Неправильно!"
            kartinka(r"images\image2.png")  # Показываем картинку ошибки
            # Цикл продолжается - вопрос повторяется
    
    # Разделитель между вопросами
    print("--------------------------------")
```

**Что тут происходит:**
- `if is_correct:` - "если ответ правильный"
- `break` - "ВЫЙДИ из цикла while (больше не повторяй)"
- `else:` - "иначе (если ответ неправильный)"
- Если `break` не выполнился, цикл `while True` повторяется снова!

**Как это работает в жизни:**
```
1. Программа: "Сколько будет 2+2?"
2. Ты: "3"
3. Программа: "Wrong! Try again." (показывает грустную картинку)
4. Программа: "Сколько будет 2+2?" (вопрос повторяется!)
5. Ты: "4"
6. Программа: "Correct!" (показывает весёлую картинку)
7. Программа переходит к следующему вопросу
```

### Часть 5: Вопросы - используем функцию

```python
# Вопрос 1
ask_question([
    "The Christmas greeting is: (Рождественское приветствие звучит:)",
    "1: Happy Christmas!",
    "2: Merry Christmas!",
    "3: Lucky Christmas!",
    "4: Lovely Christmas!"
], "2", r"images\image1.png")
```

**Разбираем:**
- `ask_question(` - вызываем функцию
- `[...]` - первый параметр: список строк (вопрос и варианты)
- `"2"` - второй параметр: правильный ответ
- `r"images\image1.png"` - третий параметр: путь к картинке

**Почему `r"images\image1.png"`?**
- `r` перед кавычками означает "raw string" (сырая строка)
- В обычной строке `\` - это специальный символ
- `r"..."` говорит Python: "не обрабатывай \, это просто обратный слеш"

Сейчас при ошибке всегда показывается `images\image2.png`.

Чтобы изменить это, найди в коде:
```python
kartinka(r"images\image2.png")
```

И замени на:
```python
kartinka(r"images\твоя_картинка_ошибки.png")
```

## [КАК СОБРАТЬ ПРОГРАММУ В EXE]

### Что такое EXE?

EXE - это готовая программа, которую можно запустить на любом компьютере с Windows, даже если там нет Python!

### Как собрать?

1. Открой командную строку (Win + R, напиши `cmd`, нажми Enter)
2. Перейди в папку с программой:
```bash
cd C:\Users\ТвоёИмя\Documents\Quiz
```

3. Запусти скрипт сборки:
```bash
python build_exe.py
```

4. Подожди 1-2 минуты
5. Готово! Файл `Quiz.exe` будет в папке `dist/`

### Что внутри EXE?

- Весь код из `main.py`
- Все картинки из папки `images/`
- Библиотека PIL
- Файл `questions-auto.json`

### Ошибка: "ModuleNotFoundError: No module named 'PIL'"

**Что случилось:** Не установлена библиотека Pillow

**Решение:**
```bash
pip install Pillow
```

### Ошибка: "SyntaxError: invalid syntax"

**Что случилось:** Ошибка в коде (опечатка, забыта скобка и т.д.)

**Решение:**
1. Посмотри на номер строки в ошибке
2. Проверь эту строку и строку перед ней
3. Частые ошибки:
   - Забыта закрывающая скобка `)`
   - Забыта кавычка `"`
   - Неправильный отступ (в Python отступы важны!)

### Картинка не показывается

**Проверь:**
1. Файл картинки существует в папке `images/`
2. Имя файла написано правильно (с учётом регистра!)
3. Путь написан с `r` перед кавычками: `r"images\file.png"`

### Программа зависла

**Что случилось:** Возможно, бесконечный цикл без выхода

**Решение:**
- Нажми Ctrl + C в консоли, чтобы остановить программу
- Проверь, что в цикле `while` есть условие выхода или `break`
