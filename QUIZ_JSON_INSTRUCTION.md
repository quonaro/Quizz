## Общая структура

Каждый JSON-файл квиза должен иметь следующую базовую структуру:

```json
{
  "title": "Название квиза",
  "description": "Описание квиза (необязательно)",
  "author": "Автор квиза (необязательно)",
  "version": "Версия квиза (необязательно)",
  "questions": [
    // Массив вопросов
  ]
}
```

### Обязательные поля

- **`title`** (string) — название квиза
- **`questions`** (array) — массив вопросов (минимум 1 вопрос)

### Необязательные поля

- **`description`** (string) — описание квиза
- **`author`** (string) — автор квиза
- **`version`** (string) — версия квиза

## Типы вопросов

### Одиночный выбор (single_choice)

Вопрос с одним правильным ответом из нескольких вариантов.

**Структура:**

```json
{
  "id": "q1",
  "type": "single_choice",
  "question": "Текст вопроса",
  "options": ["Вариант 1", "Вариант 2", "Вариант 3", "Вариант 4"],
  "correct_answer": 0,
  "points": 1,
  "explanation": "Пояснение к ответу (необязательно)",
  "images": "путь/к/изображению.jpg" // необязательно
}
```

**Поля:**

- **`id`** (string, обязательно) — уникальный идентификатор вопроса
- **`type`** (string, обязательно) — тип вопроса: `"single_choice"`
- **`question`** (string, обязательно) — текст вопроса
- **`options`** (array, обязательно) — массив вариантов ответа (минимум 2 варианта)
- **`correct_answer`** (integer, обязательно) — индекс правильного ответа (начинается с 0)
- **`points`** (number, необязательно) — количество баллов за правильный ответ (по умолчанию 1)
- **`explanation`** (string, необязательно) — пояснение, показываемое после ответа
- **`images`** (string или array, необязательно) — путь(и) к изображению(ям)

**Пример:**

```json
{
  "id": "q1",
  "type": "single_choice",
  "question": "Какой химический символ у воды?",
  "options": ["H2O", "CO2", "O2", "NaCl"],
  "correct_answer": 0,
  "points": 1,
  "explanation": "Вода состоит из двух атомов водорода и одного атома кислорода, отсюда H2O."
}
```

### Множественный выбор (multiple_choice)

Вопрос с несколькими правильными ответами.

**Структура:**

```json
{
  "id": "q2",
  "type": "multiple_choice",
  "question": "Текст вопроса",
  "options": ["Вариант 1", "Вариант 2", "Вариант 3"],
  "correct_answers": [0, 2],
  "partial_credit": false,
  "points": 2,
  "explanation": "Пояснение (необязательно)"
}
```

**Поля:**

- **`id`** (string, обязательно) — уникальный идентификатор вопроса
- **`type`** (string, обязательно) — тип вопроса: `"multiple_choice"`
- **`question`** (string, обязательно) — текст вопроса
- **`options`** (array, обязательно) — массив вариантов ответа (минимум 2 варианта)
- **`correct_answers`** (array, обязательно) — массив индексов правильных ответов (минимум 1)
- **`partial_credit`** (boolean, необязательно) — начислять ли частичные баллы за частично правильный ответ (по умолчанию `false`)
- **`points`** (number, необязательно) — количество баллов за полностью правильный ответ (по умолчанию 1)
- **`explanation`** (string, необязательно) — пояснение
- **`images`** (string или array, необязательно) — изображение(я)

**Пример:**

```json
{
  "id": "q2",
  "type": "multiple_choice",
  "question": "Какие из следующих являются языками программирования? (Выберите все подходящие)",
  "options": ["Python", "HTML", "JavaScript", "CSS"],
  "correct_answers": [0, 2],
  "partial_credit": true,
  "points": 2,
  "explanation": "Python и JavaScript — языки программирования. HTML и CSS — языки разметки и стилей соответственно."
}
```

### Текстовый ввод (text_input)

Вопрос с текстовым полем для ввода ответа.

**Структура:**

```json
{
  "id": "q3",
  "type": "text_input",
  "question": "Текст вопроса",
  "correct_answers": ["Правильный ответ 1", "Правильный ответ 2"],
  "case_sensitive": false,
  "trim_whitespace": true,
  "points": 1,
  "explanation": "Пояснение (необязательно)"
}
```

**Поля:**

- **`id`** (string, обязательно) — уникальный идентификатор вопроса
- **`type`** (string, обязательно) — тип вопроса: `"text_input"`
- **`question`** (string, обязательно) — текст вопроса
- **`correct_answers`** (string или array, обязательно) — правильный ответ или массив допустимых ответов
- **`case_sensitive`** (boolean, необязательно) — учитывать ли регистр при проверке (по умолчанию `false`)
- **`trim_whitespace`** (boolean, необязательно) — удалять ли пробелы в начале и конце ответа (по умолчанию `true`)
- **`points`** (number, необязательно) — количество баллов (по умолчанию 1)
- **`explanation`** (string, необязательно) — пояснение
- **`images`** (string или array, необязательно) — изображение(я)

**Пример:**

```json
{
  "id": "q3",
  "type": "text_input",
  "question": "Какой столицей является Франция?",
  "correct_answers": ["Париж", "Paris", "PARIS"],
  "case_sensitive": false,
  "trim_whitespace": true,
  "points": 1,
  "explanation": "Париж — столица и крупнейший город Франции."
}
```

### Сопоставление (matching)

Вопрос на сопоставление элементов из двух списков.

**Структура:**

```json
{
  "id": "q4",
  "type": "matching",
  "question": "Текст вопроса",
  "left_items": ["Элемент 1", "Элемент 2", "Элемент 3"],
  "right_items": ["Соответствие 1", "Соответствие 2", "Соответствие 3"],
  "matches": [
    {"left": 0, "right": 2},
    {"left": 1, "right": 1},
    {"left": 2, "right": 0}
  ],
  "points": 3,
  "explanation": "Пояснение (необязательно)"
}
```

**Поля:**

- **`id`** (string, обязательно) — уникальный идентификатор вопроса
- **`type`** (string, обязательно) — тип вопроса: `"matching"`
- **`question`** (string, обязательно) — текст вопроса
- **`left_items`** (array, обязательно) — элементы левого списка (минимум 2)
- **`right_items`** (array, обязательно) — элементы правого списка (минимум 2)
- **`matches`** (array, обязательно) — массив объектов с правильными соответствиями
  - Каждый объект содержит:
    - **`left`** (integer) — индекс элемента из `left_items` (начинается с 0)
    - **`right`** (integer) — индекс элемента из `right_items` (начинается с 0)
- **`points`** (number, необязательно) — количество баллов (по умолчанию 1)
- **`explanation`** (string, необязательно) — пояснение
- **`images`** (string или array, необязательно) — изображение(я)

**Пример:**

```json
{
  "id": "q4",
  "type": "matching",
  "question": "Сопоставьте страны с их столицами:",
  "left_items": ["Франция", "Германия", "Италия", "Испания"],
  "right_items": ["Мадрид", "Берлин", "Париж", "Рим"],
  "matches": [
    {"left": 0, "right": 2},
    {"left": 1, "right": 1},
    {"left": 2, "right": 3},
    {"left": 3, "right": 0}
  ],
  "points": 4,
  "explanation": "Франция-Париж, Германия-Берлин, Италия-Рим, Испания-Мадрид"
}
```

### Упорядочивание (ordering)

Вопрос на упорядочивание элементов в правильном порядке.

**Структура:**

```json
{
  "id": "q5",
  "type": "ordering",
  "question": "Текст вопроса",
  "items": ["Элемент 1", "Элемент 2", "Элемент 3"],
  "correct_order": [1, 0, 2],
  "points": 3,
  "explanation": "Пояснение (необязательно)"
}
```

**Поля:**

- **`id`** (string, обязательно) — уникальный идентификатор вопроса
- **`type`** (string, обязательно) — тип вопроса: `"ordering"`
- **`question`** (string, обязательно) — текст вопроса
- **`items`** (array, обязательно) — массив элементов для упорядочивания (минимум 2)
- **`correct_order`** (array, обязательно) — массив индексов элементов в правильном порядке
  - Каждый индекс соответствует позиции элемента в массиве `items` (начинается с 0)
- **`points`** (number, необязательно) — количество баллов (по умолчанию 1)
- **`explanation`** (string, необязательно) — пояснение
- **`images`** (string или array, необязательно) — изображение(я)

**Пример:**

```json
{
  "id": "q5",
  "type": "ordering",
  "question": "Расположите планеты от ближайшей к Солнцу до самой дальней:",
  "items": ["Юпитер", "Меркурий", "Земля", "Марс", "Венера"],
  "correct_order": [1, 4, 2, 3, 0],
  "points": 5,
  "explanation": "Правильный порядок: Меркурий, Венера, Земля, Марс, Юпитер"
}
```

**Как работает `correct_order`:**

В примере выше:
- `items[0]` = "Юпитер"
- `items[1]` = "Меркурий"
- `items[2]` = "Земля"
- `items[3]` = "Марс"
- `items[4]` = "Венера"

`correct_order: [1, 4, 2, 3, 0]` означает:
1. Первый элемент правильного порядка — `items[1]` = "Меркурий"
2. Второй — `items[4]` = "Венера"
3. Третий — `items[2]` = "Земля"
4. Четвертый — `items[3]` = "Марс"
5. Пятый — `items[0]` = "Юпитер"

## Изображения в вопросах

Вы можете добавить изображения к любому вопросу, используя поле `images`.

### Одно изображение

```json
{
  "id": "q1",
  "type": "single_choice",
  "question": "Что изображено на картинке?",
  "images": "image.jpg",
  "options": ["Вариант 1", "Вариант 2"],
  "correct_answer": 0
}
```

### Несколько изображений

```json
{
  "id": "q1",
  "type": "single_choice",
  "question": "Что изображено на картинках?",
  "images": ["image1.jpg", "image2.jpg", "image3.jpg"],
  "options": ["Вариант 1", "Вариант 2"],
  "correct_answer": 0
}
```

### Пути к изображениям

- **Относительный путь:** `"images": "image.jpg"` — файл должен находиться в той же папке, что и JSON-файл
- **Относительный путь с подпапкой:** `"images": "images/question1.jpg"` — файл в подпапке
- **Абсолютный путь:** `"images": "/home/user/quiz/image.jpg"` — полный путь к файлу
- **URL:** `"images": "https://example.com/image.jpg"` — изображение загружается из интернета

**Примечание:** При сборке исполняемого файла с встроенным квизом изображения из локальных файлов будут встроены в исполняемый файл.

## Валидация

Приложение автоматически валидирует JSON-файлы квизов по схеме, определенной в `schema/quiz_schema.json`.

### Типичные ошибки

1. **Отсутствие обязательных полей:**
   - Убедитесь, что присутствуют `title` и `questions`
   - Каждый вопрос должен иметь `id`, `type` и `question`

2. **Неправильные индексы:**
   - Индексы в `correct_answer`, `correct_answers`, `matches`, `correct_order` должны быть в пределах массива (начинаются с 0)

3. **Неправильный тип вопроса:**
   - `type` должен быть одним из: `"single_choice"`, `"multiple_choice"`, `"text_input"`, `"matching"`, `"ordering"`

4. **Недостаточно вариантов:**
   - Для `single_choice` и `multiple_choice` должно быть минимум 2 варианта
   - Для `matching` должно быть минимум 2 элемента в каждом списке
   - Для `ordering` должно быть минимум 2 элемента

5. **Неправильный формат JSON:**
   - Убедитесь, что JSON валиден (правильные кавычки, запятые, скобки)

### Проверка JSON

Вы можете проверить валидность JSON с помощью онлайн-валидаторов или инструментов командной строки:

```bash
# Проверка синтаксиса JSON
python -m json.tool quiz.json > /dev/null && echo "JSON валиден" || echo "Ошибка в JSON"
```

## Альтернативный упрощенный формат

Приложение также поддерживает упрощенный формат JSON, который автоматически конвертируется в стандартный формат.

### Отличия упрощенного формата:

1. **Поле `text` вместо `question`:**
   ```json
   {
     "type": "single_choice",
     "text": "Текст вопроса",
     ...
   }
   ```

2. **Опции как объекты с флагом `correct`:**
   ```json
   {
     "type": "single_choice",
     "options": [
       {"text": "Вариант 1", "correct": true},
       {"text": "Вариант 2", "correct": false}
     ]
   }
   ```

3. **Для `text_input` используется `expected` вместо `correct_answers`:**
   ```json
   {
     "type": "text_input",
     "expected": ["Ответ 1", "Ответ 2"]
   }
   ```

4. **Для `matching` используется `pairs` с текстовыми значениями:**
   ```json
   {
     "type": "matching",
     "pairs": [
       {"left": "Франция", "right": "Париж"},
       {"left": "Германия", "right": "Берлин"}
     ]
   }
   ```

**Рекомендация:** Используйте стандартный формат, описанный выше, так как он полностью соответствует JSON Schema и обеспечивает лучшую совместимость.
